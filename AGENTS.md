# Repository contribution rules

- Never add personal names, personal email addresses, phone numbers, credentials, or other personal identifying details to source files, documentation, or commit messages.
- For local commits in this repository, use the repository-local identity `$DROP` and `team@xrp-drop.com`. Do not set this globally.
- Automated commits must also use the repository-local identity `$DROP` and `team@xrp-drop.com`.
- Before pushing, check the commit author and committer metadata with `git log -1 --format='%an <%ae> | %cn <%ce>'`.
